# Windows 本地构建

桌面固定入口是 `ComPet.lnk`，始终指向本仓库的：

`morningmeal_Compet_V3\dist\Compet-V3\Compet-V3.exe`

后续修改源码后，在仓库根目录运行同一个命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\build.ps1
```

脚本先构建到固定的临时目录，再用隔离用户配置进行 8 秒离屏启动检查。检查成功才更新固定程序目录及快捷方式；不会自动启动正式应用。默认不生成 ZIP 或带版本后缀的发布目录。`ExecutionPolicy Bypass` 只作用于本次 PowerShell 进程。

如果固定目录内的应用正在运行，脚本会停止并提示先从托盘菜单退出，避免打断计时或覆盖正在使用的 DLL。其他旧版本不会被自动关闭。更新后仍从桌面同一个快捷方式启动。

用户配置及计时数据仍由应用保存到 `%USERPROFILE%\.morningmeal_ComPet`，构建与启动检查不迁移或覆盖这些数据。不要移动仓库目录；如需迁移，在新位置重新运行脚本更新快捷方式。

如果正式程序仍在运行，可先准备并检查构建，等用户正常退出后再运行上面的更新命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\build.ps1 -StageOnly
```

`-StageOnly` 使用固定暂存目录，不更新正式程序或桌面快捷方式，也不停止正式进程。

## 追踪与“其他”计时器

- 在“窗口分组”中使用“添加追踪窗口”，同一分组可继续添加条目，已有超过 3 项的内容完整保留。计时器通过所选分组追踪这些窗口；共享分组的计时器使用同一份追踪列表。
- 不同分组可以追踪同一窗口。所有匹配计时器分别累计，桌面只显示计时器列表中排在最前的匹配项；每个计时器仍独立遵守暂停与闲置阈值。
- 在“计时器列表”点击“添加‘其他’计时器”可创建一个兜底计时器。只有其他普通计时器均未匹配时才计入；普通计时器已匹配但被暂停或闲置时，不转计“其他”。程序自己的界面、前台识别失败和缺少输入权限也不会产生兜底累计。
- 只要存在“其他”计时器，宠物就全局响应键盘和鼠标输入，即使该计时器被暂停。删除它后恢复绑定计时器的互动限制。音效仍遵守自己的开关。
- “其他”的名称可以修改；其兜底身份会保留。不会自动给用户创建计时器、改写窗口分组或重算历史累计时间。

## 时间分布饼图

在“计时器列表”点击“时间分布”，或右键桌面计时器后选择“时间分布”，可查看所有计时器的累计时长与占比，包括“其他”、暂停和零时长的计时器。窗口打开期间每秒刷新；鼠标停在扇区上可查看对应计时器。

占比的分母是各计时器累计时间之和。重叠计时分别计入，因此合计不代表去重后的实际经过时间。该视图只读取现有累计时间，不修改或清零数据；目前没有按天历史记录，因此展示的是现有总累计。

## 排序与全部清零

计时器卡片上的“上移／下移”按列表顺序调整优先级，并立即保存。重叠匹配时仍分别累计，桌面显示列表最靠前的匹配计时器。

“计时器列表”上方的“全部清零”会先确认，再将所有计时器（包括“其他”）的累计时间归零，同时清掉未显示的小数秒和跨清零时点的累计间隔。计时器、窗口分组、排序与宠物关联保留。确认后无法撤销；取消不会改变时间。

## Windows 登录自启

在仓库根目录运行以下命令可注册当前用户登录自启，无需管理员权限：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\enable-startup.ps1
```

该脚本在当前用户的“启动”文件夹创建 `ComPet.lnk`，目标与桌面快捷方式相同，均为固定的 `dist\Compet-V3\Compet-V3.exe`。普通重新构建无需重新注册；移动仓库后需要重新设置快捷方式。自启发生在用户登录 Windows 后。

要取消自启，可在资源管理器进入当前用户的“启动”文件夹，移除其中的 `ComPet.lnk`；这不会删除程序或计时数据。

## 首次安装依赖

需要 Git 和 uv。已有 `.venv` 及依赖时无需重复安装。

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

## 验证和恢复

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
.\.venv\Scripts\python.exe -m unittest discover -s macos/tests -p 'test_*.py' -v
```

脚本只保留一份上一构建，位于 `morningmeal_Compet_V3\build\windows-previous`。如果需要恢复，退出应用后，在资源管理器中将当前 `dist\Compet-V3` 文件夹移至其他位置，再将 `build\windows-previous` 整个文件夹移到 `dist` 并命名为 `Compet-V3`；桌面快捷方式无需更改。源码、用户设置和计时数据不受此恢复操作影响。

离屏检查确认启动和资源初始化，完整桌面交互仍需实际操作验证。

## 桌面浮窗与任务切换

桌宠和桌面计时器始终从任务栏及 Alt+Tab 隐藏，包括旧配置中的 `tray_mode: false`。设置窗口仍可正常参与窗口切换；从托盘或桌宠右键菜单打开设置。该行为无需修改用户配置。

## 紧凑计时器列表

计时器使用自适应宽度的单列折叠列表，只纵向滚动。名称、累计时间和上移／下移按钮始终显示；点击名称展开分组、闲置阈值、重置和删除等设置，再次点击收起，同时最多展开一项。新计时器自动展开。排序、刷新及主题切换保留现有条目和编辑状态，展开状态仅在当前设置窗口中保留，不写入计时记录。

## 创建与重命名窗口分组

在“窗口分组”直接点击“创建分组”，即可生成一个不重名的默认分组并选中其名称。分组卡片顶部可直接编辑名称，按 Enter 或移开焦点保存；空名称或重名会在卡片内提示，保留原名。重命名同步更新所有关联计时器，保留分组顺序、窗口条目、计时历史及正在进行的窗口捕获。

## 桌宠置顶恢复

Windows 下每秒检查一次可见桌宠的实际窗口层级。如果桌宠落到普通前台应用后方，会在不激活窗口、不改变位置或大小的情况下恢复置顶。设置窗口、菜单、其他主动置顶的应用和其他虚拟桌面不触发恢复；桌宠继续从 Alt+Tab 隐藏。
